# Figma mobile design

SVG exports of the phone design from Figma, as the designer sent them. Each screen is 402×874. All text is outlined as vector paths, so the font names aren't in the files.

| File | What it shows |
|---|---|
| `Main Screen-ICEPik.svg` | Map home: profile button, search pill, locate button, "New" counter, Report button, tab bar (Home, Reports, Know Your Rights) |
| `Main Screen Click-ICEPik.svg` | Map home with a pin chosen and its alert card docked above the tab bar |
| `Alerts Nearby-ICEPik.svg` | Reports tab, "Alerts", Nearby selected: a list of alert cards |
| `Alerts Search-ICEPik.svg` | Reports tab, Search selected, with a searched place |
| `Card Big Critical.svg`, `Card Big Warning.svg` | Expanded alert card (red "Critical", amber "Warning") |
| `Card Big Critical Close.svg`, `Card Big Warning Close.svg` | The same cards when you're close by, with "Are they there? No / Yes" |
| `Submit a Report-ICEPik.svg` | Submit a Report page |
| `Rights-ICEPik.svg` | Know Your Rights: article cards |
| `Login-ICEPik.svg` | Log In: frosted-glass card over a dark blue background |
| `Signup-ICEPik.svg` | Sign Up, same style |
| `Forgot Password-ICEPik.svg` | Forgot password, same style |
| `Code Verification-ICEPik.svg` | Five-digit verification code, same style |
| `Background movement.svg` | Three keyframes of the animated background behind the log in and sign up screens |
| `Group 20.svg` | Colour palette: `#FF2828`, `#007CC9`, `#FFFFFF`, `#1D1F26` |
