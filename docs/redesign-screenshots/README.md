# Phone and tablet redesign: screenshots

Each page has a before/after image at phone size (390×844) and tablet size (820×1180), and the final layout on its own. "Before" is `main`; "after" is this branch. Desktop (1280px and wider) is unchanged, so it isn't shown.

The sightings are test fixtures from a local stand-in for the database, not real reports. Map tiles are real.
